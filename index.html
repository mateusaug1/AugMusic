Como instalar

Siga os passos abaixo para instalar o APK no seu dispositivo Android.

Ver projeto no GitHub ↗
  1. 01

    Baixe o APK

    Toque em “Baixar APK (V10)” para baixar o aplicativo diretamente do GitHub.

  2. 02

    Permita a instalação, se solicitado

    Abra Configurações do Android e procure “Instalar apps desconhecidos” ou “Permitir desta fonte”. Autorize apenas o navegador ou gerenciador de arquivos usado para abrir o APK e prefira baixar do repositório oficial.

  3. 03

    Instale e abra

    Toque no arquivo baixado e siga as instruções. Se o Android bloquear a instalação ou mostrar um aviso de segurança, confira a origem e não ignore alertas que você não reconhece.
